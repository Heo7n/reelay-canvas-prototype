# Reelay Canvas Prototype

Reelay Canvas 是一个 AIGC 创作平台的无限画布前端原型。当前阶段专注验证画布交互、生成节点、媒体素材节点和 Agent 对话栏的信息架构与交互形态。

当前项目是纯静态前端原型，没有后端、没有真实生成接口、没有账号系统、没有打包部署流程。

## 文件结构

```text
.
├─ index.html                       页面结构
├─ styles.css                       视觉样式与主题
├─ app.js                           画布、节点、素材、Agent 交互逻辑
├─ AGENTS.md                         Agent 接力开发约束
├─ data/
│  └─ model-catalog.js              图片、视频、音频模型目录
└─ docs/
   ├─ current-product-spec.md       当前产品与实现说明
   ├─ product-expansion-plan.md     其他页面与产品架构规划
   ├─ agent-handoff.md              工程交接与分支边界
   └─ model-catalog-notes.md        模型命名与来源判断
```

## 本地预览

可以直接打开 `index.html`，也可以在当前目录启动静态服务：

```powershell
python -m http.server 5174 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:5174/
```

## 当前能力

- 无限画布：缩放、平移、动态网格、空状态提示、左下角快捷键/小地图/比例工具。
- 生成节点：连续分组模型列表、比例/分辨率/画质/时长/数量/积分、缩放自适应提示词输入、素材引用、真实媒体模拟生成。
- 媒体素材节点：支持从本地拖入图片、视频、音频，按原始比例展示；项目素材库可上传、分类筛选、拖入画布或引用到生成节点；单选媒体提供可定制编辑工具栏。
- 多选操作：框选、多节点移动、可拉伸可进出的可视化组框、组级移动/解组/执行、三种布局、删除撤销。
- Agent 对话栏：可收起/展开、历史会话下拉、对话输入框、模型偏好菜单。
- 账号菜单：头像下方积分徽标、可用积分、动态累计消耗、组织/账号/外观/帮助/退出入口。
- 主题：浅色、深色、跟随系统。

## 工程状态

当前代码适合作为高保真前端原型继续迭代，还不属于生产工程。已经具备清晰的静态页面入口、主题变量、核心交互状态和产品说明文档，但生产化前仍需要补齐：

- 模块拆分：将画布、生成节点、媒体节点、Agent、主题和历史状态拆成独立模块。
- 工程工具链：引入格式化、lint、类型检查、构建流程和基础自动化测试。
- 数据层：补齐项目保存、素材持久化、撤销历史栈、会话记录和真实生成任务状态。
- 依赖治理：将外部图标库从 CDN 改成受控依赖，避免离线和版本漂移问题。
- 版本管理：当前目录需要确认有效 Git 仓库状态后再进入持续迭代。
